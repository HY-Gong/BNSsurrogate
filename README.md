# BNSsurrogate
This is a surrogate model to calculate light curves of kilonova based on Gong et al. (2024). Compared to original model, the surrogate model is fast enough to infer parameters from observed light curves by MCMC. 


#Environment Dependencies
Python 3+
PyTorch 2.15.0+ CPU version

The PyTorch can be installed from:
https://pytorch.org/

You can also use pip to install:
pip3 install torch torchvision


#Package Dependencies
pip3 install pathlib numpy matplotlib


#User Guide
An example file User_guide.ipynb is under the directory. You can open it by jupyter notebook.
